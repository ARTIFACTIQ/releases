Getting Started

Complete setup guide from installation to your first analysis

1

Install mlOS Axon

Required

Axon is the model manager that handles downloading and caching ONNX models. It's required before using Artifactiq.

Terminal
$ curl -sSL axon.mlosfoundation.org | sh

View Axon documentation →

2

Install Artifactiq

Install the Artifactiq CLI binary to your system. Supports Linux (x64) and macOS (ARM64).

Terminal
$ curl -fsSL https://artifactiq.ai/install.sh | sh

Or download directly from GitHub Releases

3

Download a Detection Model

Use Axon to download YOLOv8 or other ONNX models. Models are cached locally for fast access.

Terminal
# YOLOv8 Nano (fastest, 6MB) - requires Axon v3.4.3+
$ axon install hf/ultralytics/yolov8n --format onnx

# YOLOv8 Small (balanced, 22MB)
$ axon install hf/ultralytics/yolov8s --format onnx

# YOLOv8 Medium (accurate, 52MB)
$ axon install hf/ultralytics/yolov8m --format onnx
4

Analyze Images

Run object detection and merchandise analysis on your images. Output in human-readable or JSON format.

Terminal
# Basic detection
$ artifactiq analyze --input photo.jpg --model yolov8n

# JSON output for integration
$ artifactiq analyze --input photo.jpg --model yolov8n --output json

# Batch process a directory
$ artifactiq analyze --input ./images/ --model yolov8n --output json

Real-Time Object Detection

Artifactiq uses YOLOv8 models to detect 80+ object classes with high accuracy. The detection pipeline is optimized for both speed and precision.

  • ✓ 80+ object classes - People, vehicles, animals, household items, and more
  • ✓ Configurable confidence - Filter results by confidence threshold
  • ✓ Bounding boxes - Get precise coordinates for each detection
  • ✓ JSON export - Easy integration with your applications
